Сюда кладите .mid файлы, на которые у вас есть права:
свои сочинения, лицензированные, royalty-free или public domain.
Затем: STYLE=midi COUNT=5 python run.py   (каждый файл превращается в видео с плитками).

Чужие хиты без лицензии лучше сюда не класть: платформы автоматически
блокируют такие ролики или забирают монетизацию (Content ID).
