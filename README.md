# Stickman Piano: автоматическая фабрика видео

Код сам делает музыку (синтез пианино), рисует стикмена, который играет и прыгает, рендерит вертикальное видео 1080x1920 (30 с) и заливает его на YouTube Shorts, TikTok и Instagram Reels. По расписанию, бесплатно, на GitHub Actions.

## 1. Проверить локально (2 минуты)

Нужны Python 3.10+ и ffmpeg.

    pip install -r requirements.txt
    python generate.py --seed 42 --duration 30 --out out/video.mp4

Разный `--seed` даёт разную мелодию, темп, цвета и прыжки. `python run.py` с `DRY_RUN=1` делает то же, что делает автоматизация, но без загрузки.

### Два стиля видео
- `generate.py`: стикмен играет на пианино и прыгает.
- `generate_hop.py`: два стикмена (LEFT HAND синий, RIGHT HAND красный) прыгают по падающим плиткам-нотам, сверху надпись FIND THIS MUSIC. Тексты меняются в начале файла (`HOOK`, `HOOK_SUB`, `LABEL`).

В `run.py` переменная `STYLE` = `piano` | `hop` | `alternate` (по умолчанию стили чередуются по дням).

### Хаотичный жанр и годы (STYLE=hard, по умолчанию)
`generate_hop.py --style hard --year 2008` сочиняет оригинальный быстрый «hard beat» в духе эпохи: синкопы, скачки, трели, мутирующая фраза и барабаны (кик/снейр/хэт). Год задаёт темп, лад, плотность и тип ударных (90-е: four-on-floor, 2000-е: электро, 2010-е: EDM, 2020-е: трэп). Это стиль эпохи, а не копии конкретных песен.

### Свои MIDI
Положите .mid в `songs/` и запустите `STYLE=midi COUNT=5 python run.py`. Ударные берутся с MIDI-канала 10. Права на файлы должны быть ваши (свои, лицензированные, royalty-free).

### Мелодии public domain (готовы в `songs/`)
`python tools/make_public_domain_midis.py` создаёт MIDI: Ode to Joy, «К Элизе», Turkish March (вступление), Canon in D, Jingle Bells, Greensleeves. Бас идёт на отдельный канал, поэтому левая рука играет бас, правая мелодию. Мелодии записаны по памяти: послушайте и поправьте ноты в файле, если где-то не совпадает. `STYLE=midi MIDI_BEAT=random` кладёт под них бит случайной эпохи (`four`, `electro`, `edm`, `trap`; `none` = без бита). Новые песни добавляются строками в том же скрипте или готовыми .mid в `songs/`.

### Полные треки (по умолчанию 90+ секунд)
`DURATION=90` (по умолчанию в `run.py`). В hard-стиле у трека есть вступление (только хэты), четыре разные фразы, брейки со снейр-ролом и подъём тональности на +2 перед финалом. MIDI-мелодии идут кругами: первый проход без бита, со второго входят барабаны, дальше тональность поднимается (+2, +4). Один ролик рендерится около минуты, для 12 роликов в день запас по времени GitHub Actions большой.

### 10-15 видео в день
`COUNT=12 python run.py` (в GitHub Actions по умолчанию 12; меняется в Run workflow). `YEARS=2006-2026` ограничивает годы. Между загрузками пауза `UPLOAD_GAP` секунд.

## 2. Запустить по расписанию (бесплатно)

1. Создай **публичный** репозиторий на GitHub (для публичных минуты Actions бесплатны без лимита, для приватных 2000 мин/мес) и залей туда эту папку.
2. Settings → Secrets and variables → Actions → добавь секреты из разделов ниже. Платформу без секретов скрипт просто пропускает.
3. Actions → stickman-piano → Run workflow, чтобы проверить вручную. Дальше оно идёт само по cron из `.github/workflows/daily.yml`. Чтобы постить чаще, добавь ещё строки `- cron:`.

GitHub выключает расписание в репозитории без активности 60 дней: раз в пару месяцев заходи и жми Run workflow или делай любой коммит.

## 3. Подключение платформ

### YouTube (бесплатно, 100 загрузок/день по документации)
1. console.cloud.google.com → новый проект → включи **YouTube Data API v3**.
2. OAuth consent screen: тип External, добавь себя в Test users, потом нажми **Publish app** (иначе refresh-токен умирает через 7 дней).
3. Credentials → OAuth client ID → тип Desktop. Получишь `YT_CLIENT_ID` и `YT_CLIENT_SECRET`.
4. Локально: `YT_CLIENT_ID=... YT_CLIENT_SECRET=... python tools/youtube_token.py` → вставь токен в секрет `YT_REFRESH_TOKEN`.

Оговорка: по документации Google, видео из неаудированных API-проектов блокируются как приватные. В части источников пишут, что это ограничение недавно сняли. Проверь на первой загрузке; если видео приватное, нужно пройти YouTube API audit (форма на странице quota and compliance audits).

### TikTok (бесплатно, но с ограничением)
1. developers.tiktok.com → Manage apps → создай приложение, добавь **Login Kit** и **Content Posting API**, укажи Redirect URI.
2. `TT_CLIENT_KEY=... TT_CLIENT_SECRET=... TT_REDIRECT_URI=... python tools/tiktok_token.py` → секрет `TT_REFRESH_TOKEN`; ключ и секрет приложения тоже в секреты.
3. Режим по умолчанию `inbox`: видео прилетает в черновики TikTok, ты жмёшь «Опубликовать» в приложении (10 секунд). Режим `direct` (`TT_MODE=direct`) публикует сам, но пока приложение не прошло аудит TikTok, все посты приватные.

Полностью автономная публичная публикация в TikTok требует аудита приложения. Это ограничение TikTok, обойти его кодом нельзя.

### Instagram Reels (бесплатно)
1. Аккаунт должен быть Professional (Business или Creator).
2. developers.facebook.com → создай приложение с продуктом Instagram API, добавь свой аккаунт тестером/ролью, сгенерируй долгоживущий токен с правом `instagram_business_content_publish`.
3. Секреты: `IG_TOKEN` и `IG_USER_ID`. Для своего аккаунта проверка приложения (App Review) не нужна.

### Автообновление токенов (необязательно)
Создай personal access token с правом на секреты репозитория и положи в секрет `GH_PAT`. Тогда скрипт сам обновит `IG_TOKEN` и `TT_REFRESH_TOKEN`, когда платформа выдаст новые.

## Что внутри
- `generate.py`: сочинение мелодии, синтез звука, рисование кадров (Pillow), сборка через ffmpeg
- `uploaders/`: youtube.py, tiktok.py, instagram.py
- `run.py`: генерация, затем загрузка на все настроенные платформы
- `tools/`: одноразовые скрипты для получения токенов

Статус: генератор проверен рендером. Загрузчики написаны по официальной документации API, но с реальными аккаунтами не запускались: ошибки первого запуска смотри в логе Actions.
